# Dev Saini — Personal Portfolio Website (DC Universe Edition)

A modern, high-tech, responsive personal portfolio website for **Dev Saini**, 1st Year B.Tech Computer Science & Engineering student at **JECRC University, Jaipur**, styled in an immersive **DC Universe / Wayne Tech & Green Lantern** aesthetic.

---

## 🦇 DC Universe Custom Features

1. **Batman Overlooking Gotham (Hero Background):**
   - High-definition cinematic background featuring the Dark Knight perched upon a gothic gargoyle overlooking Gotham City at night.
   - Atmospheric Gotham rain streaks and a glowing, volumetric **Bat-Signal** beam shining across the dark sky.
   - Wayne Tech HUD tactical coordinate display and Batcomputer terminal preview (`dev_saini.cpp`).

2. **Green Lantern Energy Construct Arrow Transitions:**
   - Whenever moving between sections (via navigation links, hero action buttons, or back-to-top boost):
     - An emerald construct shockwave ring is summoned.
     - A volley of crystalline **Green Lantern construct energy arrows** shoot across the screen pointing dynamically toward the target section with particle spark trails.
     - A Green Lantern Power Ring HUD notification flashes momentarily.

3. **Wayne Tech & Green Lantern Sound Effects (Web Audio API):**
   - Built with the native **Web Audio API** (100% offline, zero external audio file dependencies, zero loading latency).
   - **Green Lantern Construct Swoosh:** Authentic crystalline laser frequency sweep and harmonic resonance when jumping between sections.
   - **Wayne Tech Interface Clicks:** Futuristic Batcomputer tactile chirp on button interactions and modal triggers.
   - **Hover Blips:** Subtle cybernetic audio feedback on hovering major links.
   - **Audio Controller:** An animated equalizer toggle (`SFX: ON / OFF`) in the navigation bar allowing users to mute or unmute audio at any time.
